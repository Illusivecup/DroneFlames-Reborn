# UPSTREAM TRACKING — DroneFlames → DroneFlames Reborn

Документ отслеживает, что меняется в **оригинальной игре DroneFlames** и в каком
состоянии находится паритет с ней у порта **DroneFlames Reborn**. Обновляется при
каждом релизе порта.

## Где живёт оригинал

Оригинальная игра — **закрытый проект, публичного репозитория с исходниками нет**.
Базис этого проекта — **DroneFlames PC Port** (автор порта @droneflamesmod,
репозиторий `makkaX2/DroneFlames-PC-Port`, создан 01.11.2026). Ветка Reborn —
надстройка над этим базисом: на 17.11.2026 1591 файл из 1680 совпадающих путей
побайтово идентичен базису, поверх него живут системы Reborn.

| Что | Где |
| --- | --- |
| Официальный Telegram-канал (ченджлоги, APK) | t.me/droneflames |
| Официальные серверы (API/сигналинг) | drone-flames.snaipix.com (всем отвечает 429 — см. NET_RESILIENCE.md) |
| Зеркало APK с историей версий | pdalife.to/droneflames-android-a52227.html (файл отдаётся через mobdisc.com за Cloudflare Turnstile) |
| Android-пакет | `com.kolesnyk.droneflames` |

| Discord-комьюнити | discord.gg/m8gyr4V6J |

Базис порта собран из распакованного APK оригинала автором порта
(@droneflamesmod): `tools/import_apk.py` извлекает `assets/`, восстанавливает
`project.godot` из `project.binary`. Поверх базиса живут Reborn-системы
(HostSim, Rust-ядро `rust/dfarmy` + `native/df_native`, оптимизации рендера, моды).

## Как подтянуть следующую версию оригинала (процедура)

1. **Достать APK нужной версии.** Канал t.me/droneflames прикрепляет APK к постам
   о релизах; зеркало — pdalife.to (страница скачивания защищена Cloudflare
   Turnstile: нужен ручной браузер — headless-скачивание блокируется).
   Готовый APK положить в `upload/` (или передать сборщику).
2. **Импорт в отдельное дерево** (не поверх рабочего кода!):
   `python3 tools/import_apk.py <путь>/DroneFlames_v0.41.4.apk` — скрипт извлечёт
   ассеты, восстановит `project.godot` и сделает коммит с тегом `v0.41.4`.
   Скрипт рассчитан на Windows-пути; на Linux правит только константы `GAME_DIR`.
3. **Diff против нашей базы**: `git diff v0.33.5.38..v0.41.4 -- game/ net/ world/ ui/ core/`
   (после импорта тег появится автоматически). Разбить на:
   контент (спрайты, звуки, карты) — переносится напрямую;
   скрипты оригинала — сливать вручную, поверх Reborn-оптимизаций
   (образец: коммит `7b67e3d`, где апстрим-фичи переносились файл-за-файлом);
   горячие пути — переносить в Rust-ядро (`rust/dfarmy`, `native/df_native`)
   с GDScript-фолбэком, как в `game/ford.gd`.
4. **Не переносить слепо**: апстрим-код без Reborn-патчей вернёт регрессии
   производительности (наш README: «сотни юнитов убивают тактовый бюджет кадра»).
   Обязательный минимум поверх апстрима: `perf_sys`, HostSim-кодек `hs_codec.gd`,
   `project.godot` (user dir `DroneFlames-Reborn`, script_export_mode=0),
   брендинг/обновлятор (`net/github_updater.gd` → наш репозиторий).
5. **Проверки перед релизом**: `cargo test` в `rust/dfarmy`; `dev/verify_game.gd`,
   `dev/mp_hostsim_test.gd`, FPS-бюджет `--bench` (см. ROADMAP.md).

## Почему мы не делаем «слепой merge» прямо сейчас

APK свежих версий отдаётся только за Cloudflare Turnstile и в TG-канале; при
отсутствии файла merge по патчноутам рискует разойтись с оригиналом в деталях
баланса и правил. Поэтому политика порта: **паритет фич реализуем сами
(Rust-first), а точный контент/баланс подтягиваем только из настоящего APK**,
как только файл окажется в `upload/`.
